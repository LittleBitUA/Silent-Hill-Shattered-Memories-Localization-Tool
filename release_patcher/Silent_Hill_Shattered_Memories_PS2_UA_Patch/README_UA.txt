================================================================
 Silent Hill: Shattered Memories — Українська локалізація (PS2)
================================================================

Цей патч робить вашу копію Silent Hill: Shattered Memories
для PlayStation 2 українською. Перекладено тексти, відмальовано
шрифт з усіма українськими літерами (включно з Є є Ї ї І і Ґ ґ).

! ВАЖЛИВО:
  Файлів гри в цьому патчі немає. Потрібен ваш ВЛАСНИЙ чистий
  ISO, здамплений з оригінального диску
  Silent Hill: Shattered Memories (USA, SLUS-21899).
  Ми не розповсюджуємо ISO гри — це нелегально.

----------------------------------------------------------------
 Що у комплекті
----------------------------------------------------------------
  PATCH_UA.bat                            ← запускати цей файл
  xdelta3.exe                             ← утиліта застосування патчу
  LittleBit_SHSM_PS2_UA_v0.8.xdelta       ← сам бінарний патч
  README_UA.txt                           ← цей файл
  HASHES.txt                              ← контрольні суми

----------------------------------------------------------------
 Як використовувати
----------------------------------------------------------------
  1. Зробіть чистий ISO зі свого оригінального диску
     (наприклад, через ImgBurn).

  2. Покладіть ваш ISO у зручне місце.

  3. Перетягніть ваш ISO мишкою на файл PATCH_UA.bat.
     АБО з командного рядка:
        PATCH_UA.bat "C:\шлях\до\вашого.iso"

  4. Зачекайте 1-2 хвилини. BAT-файл:
     - перевірить SHA256 вашого ISO (щоб переконатись, що це
       правильний регіон/версія);
     - застосує патч через xdelta3;
     - перевірить, що результат коректний.

  5. Поруч з вашим ISO з'явиться файл з суфіксом "_UA",
     наприклад:  Silent_Hill_SM_USA_UA.iso

  Цей файл — ваша українська версія. Записуйте на диск або
  запускайте в емуляторі PCSX2.

----------------------------------------------------------------
 "Це не той ISO" — що це означає
----------------------------------------------------------------
Перед патчингом BAT перевіряє SHA256 вашого ISO. Якщо хеш
не збігся, патч НЕ застосовується. Можливі причини:

  - Інший регіон. Патч зроблений ТІЛЬКИ для NTSC-U (США,
    SLUS-21899). PAL (Європа), NTSC-J (Японія), Greatest
    Hits та інші перевидання — НЕ підтримуються.

  - Ваш ISO вже модифікований (англізований, обрізаний,
    перепакований). Потрібен ЧИСТИЙ дамп з оригінального
    диску, без будь-яких змін.

  - ISO зіпсований під час дампування або копіювання.
    Спробуйте здамплити заново або перевірте носій.

  - Не той формат (CSO, BIN/CUE, MDF/MDS тощо).
    Конвертуйте у звичайний ISO 9660.

----------------------------------------------------------------
 Проблеми та рішення
----------------------------------------------------------------
> Кириличні літери виглядають як кракозябри у консолі.
  Win10/11: BAT сам перемикає консоль на UTF-8 (chcp 65001).
  Win7/8: оновіть PowerShell або відкрийте BAT у консолі з
  Lucida Console / Consolas — TrueType шрифти підтримують Юнікод.

> "Не знайдено xdelta3.exe".
  Файл xdelta3.exe має лежати В ТІЙ САМІЙ ПАПЦІ, що й PATCH_UA.bat.
  Не переносьте BAT окремо.

> "Не знайдено патч: LittleBit_SHSM_PS2_UA_v0.8.xdelta".
  Аналогічно — .xdelta файл має лежати поруч з BAT.

> "Access denied" при створенні вихідного файлу.
  Перенесіть всю папку з патчером на робочий стіл або у
  C:\Users\<ваше_ім'я>\Documents\. Деякі системні папки
  (Program Files, кореневі диски) обмежують запис.

> "xdelta3: target window checksum mismatch".
  Це означає, що під час застосування патчу вхідний ISO
  змінився (антивірус, синхронізація OneDrive/Dropbox).
  Тимчасово вимкніть синхронізацію і повторіть.

> Готовий ISO не запускається на емуляторі.
  Спробуйте оновити PCSX2 до останньої стабільної версії.
  Якщо проблема лишається — повідомте автору з логами
  емулятора (рівень логів: INFO або вище).
