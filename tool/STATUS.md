# Silent Hill: Shattered Memories — Ukrainian localization

## Translation source of truth: `TEXT_TRANSLATION/`

Single canonical home for all translation text, shared across the three
platform builds. Generated by `tool/build_shared_translation.py`.

| File                          | Hashes | Purpose |
| ---                           | ---    | --- |
| `translate_shared.txt`        | 4853   | Union of PS2 + Wii + PSP hash sets; primary source-of-truth. **Edit this for normal translation work.** |
| `translate_ps2_only.txt`      | 37     | Hashes exclusive to PS2. Edit to override shared text on PS2 only. |
| `translate_wii_only.txt`      | 87     | Hashes exclusive to Wii. Edit to override shared text on Wii only. |
| `translate_psp_only.txt`      | 28     | Hashes exclusive to PSP. Edit to override shared text on PSP only. |

Cross-platform overlap: all-three intersect = 4573 hashes (~94%).
PS2 has biggest coverage (4738), Wii 4660, PSP 4729.

Pack-time, each platform's build script invokes
`tool/pack_platform_strings.py <platform> <out.bin>` which:
1. Reads `translate_shared.txt` as `{hash: text}`
2. Overlays `translate_<platform>_only.txt` on top (overrides)
3. Filters to the platform's actual hash list (from the source .arc)
4. Feeds the rows to `strings_pack.pack()` (CYR2LAT_SUBST + platform `SH_EXTRA_SUBST`)

The legacy per-platform sources (`unpacked/translate_sys.txt`,
`translate_ui.txt`, `Duplicate.txt`, `translate_wii.txt`,
`translate_psp.txt`) are kept only as historic inputs to the shared
builder. Don't edit them after the migration — edits there are ignored.

Re-run `python tool/build_shared_translation.py` only when source .arc
files change (new platform added or different game revision). The
shared/only files persist between builds.

---

Three parallel build tracks:

- **PS2 NTSC-U** — patches SLUS_218.99 ELF (embedded Boot.arc holds Font_EUR) plus data.arc entries 1315/1316.
- **Wii NTSC-U** (R5WEA4) — patches `main.dol` (which embeds Font_EUR as a zlib stream) plus data.arc entries 1329/1330.
- **PSP NTSC-U** (ULUS) — patches `EBOOT.BIN` (same idea as Wii main.dol) plus data.arc entry 1316 only.

Reference: [consolgames-tools](https://github.com/mbystryantsev/consolgames-tools) — Wii RU port by consolgames.ru (Metallist).
Russian Wii reference patch (binary diff): `E:\Download\shsm_wii_rus_by_metallist\` — applied via `imagePatch.exe`.
Russian PSP reference: `E:\Download\SH.iso` (already-patched RU ISO; orig USA at `E:\Download\Silent_Hill_Shattered_Memories_USA_PSN_PSP-HR\`).

## Wii pipeline (`tool/build_ua_wii.py`)

The Wii engine reads the on-screen font from **`main.dol`**, NOT from `data.arc/Font_EUR`. The data.arc copy is loaded but never consulted at draw time — modifying it has no visible effect. Discovered by diffing Metallist's RU `main.dol` against the original USA `main.dol`: a single contiguous 15,363-byte diff inside the data segment, exactly where a `78 DA` zlib stream decompresses to a 36,864-byte Font_EUR.

### Layout in `main.dol` (USA NTSC-U R5WEA4)

```
DOL data section 12: file 0x3DAF80..0x453540  load 0x803DEE80  size 492992
  zlib stream    @ 0x3F9F78  decomp → 36864-byte Font_EUR
  budget         = next zlib stream at 0x3FDB98 → 15392 bytes total
```

The compressed Font_EUR must fit within **15,392 bytes** (orig USA = 15,365, Metallist RU = 15,363). Zopfli at numiterations=30 gives ~10% headroom over zlib level 9.

### `wii_patch_maindol.py` — what it builds

Source: Metallist's RU `main.dol` (already has all Russian Cyrillic + Ё via donor approach on Latin-1 supplements).
Output: `wii_extract/DATA/sys/main.dol` with our UA-modified embedded font.

Modifications on top of Metallist's font (charCount 157 → 161):

| Wii slot                  | Action                                      | Notes |
| ---                       | ---                                         | --- |
| U+042D (Э) → U+0404 (Є)   | codepoint relabel only                      | bitmap is Cyrillic Э until user redraws |
| U+044D (э) → U+0454 (є)   | codepoint relabel only                      | bitmap is Cyrillic э |
| + U+00EF (ï)              | extension; bitmap from orig USA Wii         | Metallist had stripped it |
| + U+00CF (Ï)              | extension; bitmap = copy of Latin I         | placeholder — user draws diaeresis |
| + U+0490 (Ґ)              | extension; bitmap = copy of Cyrillic Г      | placeholder — user draws hook |
| + U+0491 (ґ)              | extension; bitmap = copy of Cyrillic г      | placeholder — user draws hook |

The two streamSize fields (BE at 0x596C and LE at 0x5974) and the outer RW chunk size at 0x5888 are NOT updated — Metallist's font proves the engine doesn't enforce them.

### `strings_pack.py` substitutions for Wii

`CYR2LAT_SUBST` (shared with PS2, applied first):
```
А В Е К М Н О Р С Т Х → A B E K M H O P C T X    (uppercase Latin lookalikes)
З → 3                                              (no uppercase З in fonts)
І → I, і → i                                       (UA-specific Latin lookalikes)
а е о р с у х → a e o p c y x                      (lowercase lookalikes)
```

`SH_EXTRA_SUBST` env var (Wii-only, set by `build_ua_wii.py`):
```
Ї → Ï      (Latin Ï, in Wii font via the U+00CF extension)
ї → ï      (Latin ï, restored from orig USA Wii font)
```

Letters that pass through as native Cyrillic (must exist in the embedded font):
```
Б Г Д Ж И Й Л П У Ф Ц Ч Ш Щ Ъ Ы Ь Э Ю Я
б в г д ж з и й к л м н п т ф ц ч ш щ ъ ы ь э ю я
Ё ё
Є є           (using rotated Э/э bitmaps until user redraws)
Ґ ґ           (using Г/г bitmaps + hook, until user redraws)
```

### `wii_arc_patch.py` — what it touches

In-place patch inside the 1.5-GB `data.arc`, sector-aligned slot replacement (no full rebuild):

| idx  | hash       | role            | source                |
| ---  | ---        | ---             | ---                   |
| 1329 | 0x2C238264 | translate_sys   | `translate_sys_wii.bin` |
| 1330 | 0x2C238276 | translate_ui    | `translate_ui_wii.bin`  |

Font_EUR at idx 408 is intentionally NOT touched (engine doesn't use it).

### Build pipeline

```
python tool/wii_dump_strings.py        # one-time: produces unpacked/translate_wii.txt
                                       #   pre-populated with ~1087/4660 PS2 translations
                                       #   via hash matching

python tool/build_ua_wii.py            # full build chain:
                                       #   1. wii_patch_maindol.py → patched main.dol
                                       #   2. strings_pack.py (SH_EXTRA_SUBST=Ї=Ï,ї=ï)
                                       #   3. wii_arc_patch.py → in-place data.arc
                                       #   4. wit COPY wii_extract/ → ISO (4.5 GB)
                                       #   5. DolphinTool convert ISO → RVZ (~3.3 GB)
```

Final RVZ at `UA_wii/Silent Hill - Shattered Memories (UA).rvz`.

### Glyph editor (Wii)

```
python tool/wii_kfont_png_edit.py extract 0x0490 --out unpacked/glyphs_wii/gh_upper.png
# edit the PNG in any image editor (keep dimensions)
python tool/wii_kfont_png_edit.py inject 0x0490 --in unpacked/glyphs_wii/gh_upper.png
# rebuild RVZ
python tool/build_ua_wii.py
```

Edits write through to the embedded zlib stream in `wii_extract/DATA/sys/main.dol`.

## PSP pipeline (`tool/build_ua_psp.py`)

Source ISO: `Silent_Hill_Shattered_Memories_USA_PSN_PSP-HR.iso` (NTSC-U ULUS).

PSP engine reads its font from `EBOOT.BIN` — same mechanism as Wii's
`main.dol`. The orig EBOOT.BIN is signed/encrypted (`~PSP` magic, 4744656
bytes). Metallist distributed a pre-patched RU ISO with a DECRYPTED
EBOOT.BIN (`7F ELF` magic, 4744308 bytes). Our pipeline uses Metallist's
decrypted EBOOT as base and re-patches its embedded font.

### Layout in EBOOT.BIN (Metallist's decrypted version)

```
zlib stream @ 0x34916C  → 32768-byte Font_EUR
budget       = next zlib at 0x34BDEC → 11392 bytes total
sub-header   @ 0x4D18  (different offset from PS2/Wii)
```

### `psp_patch_eboot.py` — what it builds

Same UA modifications as Wii (charCount 157 → 161):
- U+042D Э → U+0404 Є (codepoint relabel only; user redraws PNG)
- U+044D э → U+0454 є
- + U+00CF Ï (copy of Latin I; user adds dots)
- + U+00EF ï (restored from orig USA PSP)
- + U+0490 Ґ (copy of Cyrillic Г; user adds hook)
- + U+0491 ґ (copy of Cyrillic г; user adds hook)

`SH_EXTRA_SUBST='Ї=Ï,ї=ï'` is set by `build_ua_psp.py` so the Ukrainian
Ї/ї codepoints get substituted to Latin Ï/ï at string-pack time. The
font has Latin Ï/ï records (via the extensions above) to render them.

### Glyph PNG auto-injection

`build_ua_psp.py` walks `unpacked/glyphs_psp/` after the base font patch
and injects every user-edited PNG matching a known codepoint
(`PNG_GLYPH_MAP` in the script). To edit a glyph manually:

```
python tool/psp_kfont_png_edit.py extract 0x00CF --out unpacked/glyphs_psp/i_diaeresis_upper.png
# edit the PNG (keep dimensions; 0=transparent, 255=opaque)
python tool/build_ua_psp.py   # rebuild — the PNG gets re-injected automatically
```

### `psp_arc_patch.py` — what it touches

`PSP_GAME/USRDIR/DATA.ARC` in place:
- idx 1316 (translate_sys) — only one Metallist patches; engine reads from sys only
- idx 1317 (translate_ui) — NOT touched (unused on PSP)
- idx 384 (Font_EUR) — NOT touched (engine reads font from EBOOT)

### Build chain

```
python tool/psp_dump_strings.py   # produces unpacked/translate_psp.txt
                                  # ~1237/4729 strings (26.2%) auto-ported
                                  # from PS2 + Wii + Duplicate via hashes

python tool/build_ua_psp.py       # 1. sync psp_extract_work/ from orig
                                  # 2. patch EBOOT.BIN font
                                  # 3. pack translate_psp.txt (SH_EXTRA_SUBST)
                                  # 4. patch DATA.ARC sys
                                  # 5. pycdlib rebuild ISO
```

Output: `UA_psp/Silent Hill - Shattered Memories (UA).iso` (~967 MB).
Runs on **PPSSPP** (any version) or **CFW PSP** (unsigned EBOOT requires
custom firmware — same constraint as Metallist's RU patch).

External deps: `pip install pycdlib`, `7-Zip` for initial ISO extraction.

## Known limitations

- **Cyrillic Л on Wii**: rendered glyph atlas may have FIFO eviction below threshold (~100 records containing Л). Investigation pending; Metallist's RU translation hits the threshold naturally because Russian text has heavy Л usage. UA needs more translated rows to reach it.
- **Є є Ї Ґ ґ initial bitmaps**: placeholders (rotated/copied), need user redraw via `wii_kfont_png_edit.py`.
- **igc.arc** (cinematic subtitles): not yet handled; in-game movie subs stay English on both platforms.
